# Guía de demostración SIGIP-DP

**Guion vigente para esta entrega:** [34 — Presentación de los cambios](34_GUION_PRESENTACION_CAMBIOS.md). Sustituye las instrucciones históricas de memoria/reset y los ejemplos de cierre directo de Investigación de esta guía. La instancia publicada usa SQLite, prórrogas provisionales, verificación y constancia de envío antes de cerrar Investigación.

Actualización 16-oct-2026: al revisar un informe de Investigación, registre la constancia del formulario de verificación y confirme revisión. «Aprobar informe verificado» deja pendiente el envío. Ingrese como investigador asignado, abra En ejecución, registre la constancia del envío al defensor y cierre. El control de misiones permite descargar XLSX con filtros. La solicitud de ampliación de términos se registra desde ejecución; decidirla y remitir actividades requieren política aprobada todavía no precargada. IRIS es una referencia sin conexión; los avisos no afirman envío de correo. Detalle: [informe 27](27_AJUSTES_INVESTIGACION_2026_10_16.md).

## Guion breve de presentación de 6 a 8 minutos

Cambie de perfil con **Cerrar sesión**, área, **Perfil de acceso** e **Ingresar al portal**. Los formularios contienen ejemplos ficticios para agilizar la presentación; conserve esos valores o cambie sólo el identificador.

Para una presentación corta haga los pasos 1–6 y mencione los otros perfiles desde el selector. Para repetir el recorrido, restablezca la información inicial y use los mismos identificadores. Evite restablecer durante una demostración compartida porque afecta los datos de todos los visitantes del Space.

## Preparación

Abra `http://localhost:5173` o `https://shcampinof-reparto-misiones-dndp.hf.space`. Confirme que se muestren el logo oficial, las pestañas **Investigación / Víctimas** y el selector **Perfil de acceso**. Si una ejecución anterior dejó cambios, ingrese como **Administrador del sistema** y use **Restablecer información inicial**.

### Nuevo acceso por contexto

1. Seleccione **Investigación** o **Víctimas** en las pestañas horizontales.
2. Elija en **Perfil de acceso** uno de los perfiles filtrados para esa área.
3. Pulse **Ingresar al portal**. El selector facilita el guion, pero la cuenta autenticada y el backend siguen determinando los permisos y módulos habilitados.
4. Use **Cerrar sesión** en la cabecera para regresar y cambiar de perfil.

La interfaz usa el logo PNG oficial suministrado. Continúan pendientes una variante horizontal o vectorial autorizada y los archivos web licenciados de Geomanist.

## Limitaciones que deben explicarse

- El Space es público y sirve sólo para presentación; no es el MVP productivo ni el entorno institucional.
- La información vive en memoria durante la ejecución y puede restablecerse.
- Cuando no existe plazo vigente, no se muestran métricas temporales y el catálogo indica que el plazo es parametrizable.
- No hay Oracle, SharePoint, AD/Entra ID, correo real, migración histórica ni interoperabilidad institucional.
- Nunca se incluyen datos personales reales, documentos institucionales, secretos ni conexión Oracle.
- La futura persistencia Oracle debe sustituir la interfaz de repositorio sin trasladar lógica de negocio al frontend.


### Entrega documental y actuación para la presentación

En el investigador, abra **En ejecución**. Escriba una actuación y pulse **Registrar actuación**: muestre la confirmación y el historial en la misma tarjeta. Para el informe, seleccione **Forma de entrega → Cargar PDF → Usar PDF de ejemplo**, y pulse **Entregar informe**. También puede elegir una URL HTTPS de SharePoint o una referencia. Cambie al PAG y abra **Por revisar**: descargue el PDF, revise y apruebe; una devolución conserva la versión anterior y habilita la corrección. Las nuevas cargas del demo se eliminan al reiniciar/restablecer.
