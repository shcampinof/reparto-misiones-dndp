# Aplicación de identidad visual

## Colores aplicados

- Azul institucional principal: `RGB 7, 71, 148` (`#074794`).
- Azul institucional secundario: `RGB 47, 100, 173` (`#2F64AD`).
- Colores complementarios para estados: verde `RGB 34, 141, 78` (`#228D4E`) y amarillo `RGB 230, 187, 54` (`#E6BB36`).
- Los fondos y bordes usan neutros claros; éxito, advertencia y error se reservan para información de estado y mantienen contraste legible.

## Tipografía utilizada

El manual define Geomanist como familia principal y Trebuchet para el rótulo del imagotipo. Como no se recibió un archivo web autorizado de Geomanist, la interfaz utiliza una única familia sans serif de sistema: `Segoe UI`, con `Arial` como respaldo. El rótulo incluido en el PNG oficial no se reconstruye ni sustituye.

## Componentes normalizados

Se normalizaron cabeceras, pestañas, bandejas, botones, campos, mensajes, indicadores, tarjetas de caso, stepper y panel lateral mediante variables CSS comunes de color, tipografía, espaciado, borde, radio, sombra y foco.

## Sustituciones necesarias

La tipografía Geomanist se sustituye temporalmente por la pila de sistema indicada. No se descargaron ni publicaron fuentes externas.

## Activos oficiales pendientes

Se incorporó el PNG vertical suministrado, conservando proporción, transparencia y área libre. Para una futura cabecera compacta queda pendiente recibir de la Oficina de Comunicaciones una versión horizontal oficial, preferiblemente vectorial, y los archivos web licenciados de Geomanist.
